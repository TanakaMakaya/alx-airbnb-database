# Advanced SQL Scripts for AirBnB Database

This directory contains advanced SQL queries for analyzing and retrieving data from the AirBnB database. Each script demonstrates the use of joins, subqueries, aggregations, and window functions.

- **joins_queries.sql**: Demonstrates INNER JOIN, LEFT JOIN, and FULL OUTER JOIN.
- **subqueries.sql**: Contains correlated and non-correlated subqueries for analytical tasks.
- **aggregations_and_window_functions.sql**: Shows use of aggregation and window functions (RANK).

Each script is commented and ready to run against the normalized AirBnB schema.
